## 1. 話の背骨（最初の1分で話す流れ）

1. **きっかけ**：【自分が「発想力」に悩んだ場面、またはひらめきワークで見たこと】
2. **課題**：発想力を鍛えたい会社員は多い。けれど、何をすればいいか分からず、学んでもその場限りで習慣にならない
3. **着目点**：「鍛えよう」とすると続かない。だから、鍛えると言わずに、毎日つい触ってしまう遊びにした
4. **仕組み**：伏せたカードで作る「読めるのに正体が分からないお題」。人は分からないものを分かろうとする。その境目で発想が動く
5. **ログとしての形**：記録は日付ではなく「生まれる年」で並ぶ「発明年表」。自分の想像の世界が積み上がって見える
6. **これから**：個人で続くかを確かめ、コンテストや発明SNSへ広げる

## 3. こだわりの記録（触って直したところ）

面接で「どこにこだわったか」と聞かれたときの具体例。**「何を変えたか」より「なぜ変えたか」を話す**

| 変えたこと | なぜ |
|---|---|
| 画面に「鍛える」「スコア」「レベル」を出さない | 意図が見えると構えて続かない |
| 伏せたカードから選び、選ばなかったカードは見せない | 比べて選ぶと、いつもの発想に戻る |
| アプリにAIを使わない | 考えるのは自分。AIが考えると価値がなくなる |
| アプリ名を「フューチャー日記」→「発明日記」 | 遊びの中心が「発明」だから |
| 品詞をまたいで意味が重なる組み合わせを出さない（うとうと×眠る など） | お題がただの説明になって、分からなさが消える |
| 動詞に過去の形を足した（隠れる／隠れた） | 同じ語でもお題の物語が変わる。バリエーションが増える |
| 名詞にサービスを足した（保険・宅配便・SNS など） | モノだけでなく、コトの発明も考えられるように |
| 単語は50語にこだわらず、発想が広がるかで選んだ | 数よりお題の質 |
| カードをめくった後の表示時間を1秒→0.2秒 | テンポ。選んだ語は上の枠に残るので、長く見せなくてよい |
| 年表を下が過去・上が未来に | 発明が積み上がっていく感覚 |
| アイデアの入力を任意に（空なら確認だけ出す） | 見るだけでも発想は起きる。書けない人を止めない |
| 「±1」ボタンを消した | 機能が余分。細かく変えたい人は数字を直接入力できる |
| 名前画面の見出しを消した | 入力欄の表示だけで伝わる。画面の要素は少なく |
| 「これまでの発明」→「これからあなたがする発明の数」 | 発明は未来に生まれるもの |
