## 1. 誰のどんな課題を解決するのか

勉強や仕事で「正解のある問い」に向き合う時間が長く、自由に想像する機会が少ない高校生以上の人。

想像力は使わないと衰えます。それでも「発想力を鍛えよう」と言われると、構えてしまって続きません。発想法の本やワークショップで頭が柔らかくなる体験をしても、それはその場限りで、日常には残りません。

私はこれまで、ことばのカードを組み合わせて発想する「ひらめきワーク」というワークショップを作ってきました。【要確認：どこで・誰に向けて実施し、どんな反応があったか】場では盛り上がる一方で、終わればそれきりになることに課題を感じていました。

## 2. どんな価値を提供するのか

ワークショップでしか起きなかった「偶然のことばから発想する体験」を、1人で、毎日、遊びとして続けられるようにします。

ユーザーは伏せたカードを4枚引いて「こっそり光る几帳面な図書館」のようなお題を作り、「それって、どんな図書館？」「何年にできそう？」に答えるだけです。答えた発明は「発明No.」付きで記録され、生まれる年の順に並ぶ「発明年表」として積み上がっていきます。

この流れには、発想の要素を仕込んでいます。

- 偶然の組み合わせで、思い込みを外す
- 抽象的なことばを、具体的なモノやサービスに落とし込む
- 未来や過去という時間軸で考える

ただし、画面には「鍛える」「上達」「スコア」といったことばを一切出していません。学びの意図は隠し、あくまで「自分だけの未来の発明を集めるゲーム」として設計しました。続けるうちに、自分の想像の世界観が年表という形で見えてきます。

## 3. どんなビジネスモデルを想定しているのか

個人向けは無料で提供し、遊ぶ人の母数と、発明データの蓄積を優先します（データは端末内のみ）。

収益は、発想の場をつくる法人・教育機関向けの有料プランを想定しています。

- **学校（探究学習）**：授業の導入で全員が同じお題に答え、クラスの「発明年表」をつくる
- **企業研修・アイデアソン**：本題の前のウォームアップとして使う。業界や自社サービスに合わせた語のセットを提供する
- **ワークショップ運営者**：ファシリテーター向けに、お題の配信や、参加者の発明の一覧を提供する

まずは個人向けで、遊びとして続くかを検証します。そのうえで、ワークショップ運営者に小さく使ってもらうところから始めるのが現実的だと考えています。【要確認：実際に声をかけられる相手がいるか】

- **語の選び方**：
  - 形容詞は人の性格を表すことばにして、モノに人格が出るようにした
  - 動詞には過去の形も加え、お題のバリエーションを増やした
  - 名詞にはモノに加えてサービス（保険・宅配便・SNS など）も入れ、コトの発明もできるようにした
  - 品詞をまたいで意味が重なる組み合わせ（うとうと×眠る など）は出ないようにした
- **AIの使い方**：
  - 要件定義書を先につくり、それを渡して段階ごとに実装させた
  - 見た目の方向性・単語の候補出し・テストは Claude に任せ、採否は自分で決めた
