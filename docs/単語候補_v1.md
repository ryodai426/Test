## 同じお題に並べない組み合わせ（品詞をまたぐもの）の案

同じ意味が重なって、お題がただの説明になってしまう組み合わせです。採用した語に合わせて、コードの `CONFLICTS` に入れます。

| 組み合わせ | 理由 |
|---|---|
| おしゃべりな × 語る | 「話す」が重なる |
| 慎重な × おそるおそる | 「用心深い」が重なる |
| のんきな × まったり | 「のんびり」が重なる |
| 律儀な × きちんと | 「まじめ」が重なる |
| こつこつ × 粘り強い | 「続ける」が重なる |
| ぐんぐん × のびる | 「のびる」が重なる |
| ゆらゆら × 浮かぶ | 「ただよう」が重なる |
| くるくる × 回る／ぐるりと × 回る | 「回る」が重なる |
| うとうと × 眠る | 「眠る」が重なる |
| 光る × 照明 | 照明は光るのが当たり前 |
| 眠る × 枕／眠る × ふとん | 使い方そのままになる |
| 運ぶ × 電車 | 使い方そのままになる |
| 映す × 鏡／映す × カメラ | 使い方そのままになる |
| 守る × 鍵 | 使い方そのままになる |
