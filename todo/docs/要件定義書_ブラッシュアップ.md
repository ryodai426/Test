# わすれないTODO 要件定義書 ブラッシュアップ版

元の要件定義書【最終版】をもとに、「本質的な悩み」に照らして見直した点をまとめます。

## 本質的な悩み（元の要件定義書 p.20 より）

| 悩み | 何が起きているか |
|---|---|
| 傾向1：認識してるのに、実行タイミングで忘れる | 「知っている」と「その時に思い出す」は別。思い出すきっかけが要る |
| 傾向2：注意が逸れると、元の目的が消える | スーパーで別の物に気を取られる、店を出る時に傘を忘れる |
| 傾向3：記録する前に流れる | 思いついた瞬間に書けないと、すぐ消える |

加えて今回の要望：**自分のスマホからも、会社のPCからも、同じ予定を入れられること。**

---

## 見直した機能

### 1. 端末をまたいだログイン（新規・最重要）
- **元の仕様**：ユーザー名だけで識別／同じ名前は登録できない／ブラウザに7日間保存
- **問題**：スマホで「りょう」を作ると、会社PCで「りょう」と入れても「使われています」で入れない。逆に名前で入れるようにすると、名前を知っている他人も入れてしまう。7日ごとの再ログインは会社PCで面倒。
- **変更**：
  - 最初の端末で名前を決める（パスワードなしは維持）
  - 2台目は、1台目の「⚙ 設定 → この端末以外でも使う」で出る **6桁コード（10分・1回限り）** を入力して入る
  - ログインは **使うたびに延長（180日）**。会社PCで毎週入り直す必要なし
  - 総当たり対策として、コードの入力ミスが10回続くと10分止める

### 2. ワンボタン登録（傾向3）
- **元の仕様**：タイムテーブル外の余白を押すと、中身のない「とりあえずタスク」ができる。一覧は「14:23に登録」とだけ出る
- **問題**：時刻しか残らないので、あとで「何だったか」が思い出せない＝**傾向3を解決できていない**。また「余白を押す」は気づきにくい。
- **変更**：
  - スマホは画面下中央の大きな「＋メモ」、PCはサイドバー最上部の入力欄（<kbd>N</kbd>キーでも開く）
  - **ひとことだけ**書いて Enter（空でも保存できるので、元の「ワンボタン」も残る）
  - スマホはタップした瞬間にキーボードが出るようにした
  - 一覧には「今日 14:23 に記録『田中さんに電話』」と、ひとことも出る

### 3. 段階的リマインド（2分→5分→10分）
- 元の仕様どおり、2分・5分・10分後にだんだん強く知らせる（10分後は画面中央に大きく）
- 通知文にひとことを入れる：「『小麦粉』の続き、いま書いておきますか？」
- 詳細を書いた（＝予定にした）時点で止まる

### 4. タスクの種類（傾向1）
- **元の仕様**：一般／会議／朝当番／買い物／リマインダーを選ぶだけ。通知は別に毎回チェック
- **問題**：種類を選んでも何も変わらず、入力の手間だけ増える
- **変更**：**種類を選ぶと通知のタイミングが自動で入る**（元の通知仕様をそのまま初期値に）
  - 会議：30分前・5分前・時間ちょうど
  - 当番：前日20:00・30分前・時間ちょうど
  - 一般／リマインダー：時間ちょうど
  - あとから自由に足し引きできる

### 5. 予定とタスクを1つに統合
- **元の仕様**：「タスク情報」と「カレンダー・スケジュール情報」が別々
- **問題**：「会議」は予定でもありタスクでもある。二重に入れることになる
- **変更**：1つにまとめ、日付・時刻があればカレンダーに、なければ「いつかやる」に出る

### 6. 共有グループの通知は「誰に」を選べる
- 時間のリマインドは、基本は作った本人に届く
- 共有グループでは「メンバー全員にも通知する」を選べる（家族のゴミ出し当番など）

### 7. 持ち物チェックリスト（傾向2）
- **元の仕様**：位置情報（家を出る時・お店を出る時）で自動表示
- **問題**：Webアプリ（Safari）は、アプリを閉じている間に位置情報を見張れない。実際には動かない
- **変更**：
  - 「家を出る時」→ **決まった時間に通知**（例：平日7:00）＋その時間帯にアプリを開くと全画面で表示
  - 「お店を出る時」→ **買い物リストを全部チェックした瞬間に表示**（買い物が終わった＝店を出るタイミング。位置情報なしで同じ効果）
  - チェックは**毎日自動でリセット**
  - 「家を出る時」「お店を出る時」は最初から用意（テンプレート）

### 8. 買い物リスト
- 元の仕様どおり、全部チェックしたら自動で完了
- 「小麦粉、卵、牛乳」と読点で区切って一度に追加できる
- チェック済みは下に移動してグレー表示
- 共有グループの買い物リストは、家族の誰が買っても全員に反映

### 9. 削った・後回しにしたもの
| 機能 | 理由 |
|---|---|
| メンバーのオンライン表示 | 悩みの解決に関係しない |
| 予定ごとの「共有するかどうか」 | グループで決まる（個人グループ＝自分だけ）ので不要 |
| タイマー | 元の仕様どおり初版では作らない |

## 使い方の想定（スマホ ⇄ 会社PC）

1. スマホでURLを開き、名前を入れてはじめる（Safariの共有ボタン →「ホーム画面に追加」推奨）
2. スマホの ⚙ →「この端末以外でも使う」→ 6桁コードを出す
3. 会社PCでURLを開き、「コードでログイン」に入力
4. 以降はどちらで入れても、20秒以内にもう一方にも出る
5. 通知は端末ごとに「🔔 この端末で通知を受け取る」をオン（両方オンなら両方に届く）
